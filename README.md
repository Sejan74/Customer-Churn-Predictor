# Customer-Churn-Predictor
# 📊 Customer Churn Intelligence Dashboard

A full-stack Machine Learning web application designed to evaluate customer retention risk and predict churn probabilities for telecommunication providers. Built with XGBoost and Streamlit.

---

## 🌟 Key Features
- **Predictive Analytics:** Uses a trained XGBoost model to compute precise churn risk percentages based on customer usage and billing patterns.
- **Interactive UI:** A modern Streamlit dashboard featuring intuitive sliders, select boxes, and status cards.
- **Automated Recommendations:** Generates real-time business retention strategies for high-risk customers and up-sell opportunities for loyal accounts.

---

## 🛠️ Tech Stack & Dependencies
- **Programming Language:** Python
- **Machine Learning:** Scikit-Learn, XGBoost, Joblib
- **Data Manipulation:** Pandas, NumPy
- **Web Framework:** Streamlit
